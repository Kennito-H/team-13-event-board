## Team Roles

### PR Approver (Kenny)
Reviews and approves pull requests before merging to `dev`; ensures code follows the 4-layer architecture and Result pattern conventions.

### Scrum Masters (Rafael and Jonathan)
Runs standups, manages the sprint board, tracks blockers, and keeps the team on schedule with branch/PR deadlines.

### Tech Lead (Jason)
Owns architectural decisions, resolves conflicts between feature implementations, and maintains `CONTRACTS.md`.

### QA Engineer (Richard)
Writes and runs tests, verifies features end-to-end before sprint merges, and catches regressions across shared services like `IEventService` and `IRSVPService`.
